The hole tree breaks if you mine 1 , 2 or 3 blocks (The blocks you have to mine are determined by the enchantment level) of the wood which are connected.You lose 4 durability per log the enchantment breaks.

#### 🔼 Different Levels 

- Level 1 : 
  - You have to break three block of the wood of the tree that the hole tree breaks
- Level 2 : 
  - You have to break two block of the wood of the tree that the hole tree breaks
- Level 3 : 
  - You have to break one block of the wood of the tree that the hole tree breaks

#### ✅️ Compatibility 

- Emerald Axe

#### 💼 Obtain

- Can be enchanted on a book with an enchanting table
- Can be enchanted on the suported items in the enchanting table
- Can be traded with a librarian
- Can be found in Chests (e.g. in an strongholds library chest)

#### ❌️ Incompatibility

- Multi Break
- Mending
- Unbreaking
- Eficiency
